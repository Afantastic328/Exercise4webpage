# 🎓 校园需求墙 (Campus Hub)

一个基于 **Vue 3 + Vite** 的校园需求发布与接单平台。学生可以浏览需求、按分类筛选、接单，也可以发布新需求。

## ✨ 功能特性

- **需求列表展示** - 卡片式布局，显示标题、分类、描述、时间、地点、发布者
- **分类筛选** - 支持按"失物招领/二手交易/兼职招聘/校园活动"筛选
- **发布需求** - 填写完整信息后可发布新需求，支持姓名和学号验证
- **接单功能** - 点击"我要接单"按钮接单，同一时间只能接一单
- **自动消失** - 已接单的需求 1 分钟后自动从列表移除
- **响应式设计** - 适配桌面和移动端

## 🛠️ 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **Composition API** - 使用 `<script setup>` 语法

## 📝 使用说明

### 浏览需求

- 页面左侧显示所有需求卡片
- 使用顶部下拉框按分类筛选
- 每张卡片显示：标题、分类、描述、时间、地点、发布者

### 接单

1. 点击卡片上的"我要接单"按钮
2. 按钮变为绿色"接单成功"
3. 其他需求按钮自动禁用（同一时间只能接一单）
4. 1 分钟后该需求自动从列表消失

### 发布需求

1. 在右侧表单填写所有必填字段：
   - 标题
   - 分类
   - 描述
   - 时间
   - 地点
   - 姓名
   - 学号
2. 所有字段填写完成后，按钮显示"发布需求卡"
3. 点击按钮发布，新需求出现在列表顶部

## 🎨 设计规范

- **主题色**：紫色系（#7c3aed, #8b5cf6）
- **背景色**：浅紫 (#f3e8ff)
- **卡片样式**：白色背景 + 深紫色刘海 + 圆角阴影
- **按钮反馈**：悬停放大、点击缩小、禁用灰色

## 📚 Vue 3 核心概念

本项目涵盖的 Vue 3 核心语法：

- **v-for** - 循环渲染列表
- **v-if / v-else** - 条件渲染
- **v-model** - 双向数据绑定
- **Props** - 父组件向子组件传递数据
- **Emits** - 子组件向父组件发送事件
- **ref / computed** - 响应式数据与计算属性
- **onMounted** - 生命周期钩子
